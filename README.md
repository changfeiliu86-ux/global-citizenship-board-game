# Global Citizenship Board Game

Realtime multiplayer board game for classroom discussion around SDGs, virtues, and argumentation.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:11466`.

## Deploy to Render

This repo includes `render.yaml`, so Render can auto-detect settings.

1. Push this project to a **public GitHub repo**.
2. In Render, choose **New +** -> **Blueprint**.
3. Connect your GitHub and select this repo.
4. Deploy and wait for build to finish.
5. Share the Render URL with players.
